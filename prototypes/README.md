# Prototypes

Kept on purpose as primary sources, not throwaway code.

- `keymap-prototype.html`: the single-file prototype that settled the
  three-mode keymap (wayfinder ticket 09, 2026-09-02). Double-click to
  run. The first `<script>` block is the pure state machine and keymap
  that the real app ports; the page shell is the seed of the in-app
  tutorial page. The decisions it produced live in
  `.scratch/h11y-sampler/requirements.md`.
